任务：从一条 STDS 操作描述中提取“当前动作直接处理的零件或物料名称”。

操作描述：
{operation_des}

规则：
1. 只提取被拿取、夹持、释放、落位、放置、安装、插接、粘贴或移动的零件/物料。
2. 不要把人工、机器人、吊具、拧紧枪、扫码枪、工装、夹具、工作台、小车、托盘车等执行者、工具、设备或目的位置当成零件。
3. 名称必须是输入原文中的连续文字，保留原有中文、英文和大小写，不翻译、不补充、不猜测零件号。
4. 描述含数量时只返回零件名称，不返回数量。例如“拿取4个螺栓”返回“螺栓”。重量始终按一个零件的单重处理。
5. 若一个描述同时出现工具和零件，只返回被工具处理的零件。例如“用吊具夹持Tray”返回“Tray”。
6. 若描述只有工具/设备动作，或无法确定零件，part_name 返回 null。

示例：
- “人工A拿取主低压线束” → 主低压线束
- “人工A用吊具夹持Tray” → Tray
- “人工A操作吊具落位Tray到toptooling小车上” → Tray
- “将水冷板放置到工作台” → 水冷板
- “拿取4个螺栓” → 螺栓
- “人工A拿取拧紧枪” → null
- “人工A移动吊具” → null

只输出结构化结果：
- part_name：字符串或 null
- reason：一句简短理由
