# 规则
1. 只比较当前动作与各候选 operation_label、parameter_text、variable_hints 的语义是否一致。
2. 必须选择一整条经验；后续所有变量都将沿用它，禁止把多条经验的变量提示混合使用。
3. 不得修改最终 Chartcode，也不得凭空补充列表外的经验。
4. index 必须严格等于候选列表中某条记录的 index，不要默认选择第一条。
5. reason 简短说明当前动作为什么更符合该经验。

# 输出
只输出 JSON，且只能包含 index 和 reason：
{{"index": 1, "reason": "当前动作与该经验描述的转身动作一致"}}
